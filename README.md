# SQPE catalog

A versioned bibliography and editorial profiles for semantic query processing research, related methods, and product documentation. The reading interface is https://sqpe.dev/catalog/.

`data/records.json` is the authoritative dataset. `data/reference-inventory.json` accounts for every bibliography bullet in the initial research input, including duplicates and unresolved citations. Imported metadata is explicitly pending verification. Existing profile review statements are preserved; migration does not constitute a new review.

Suggest a source or correction through Issues, or edit the data in a pull request. See CONTRIBUTING.md. Run `npm test` before submitting. Releases identify reproducible snapshots; the website pins a commit and checksum.
